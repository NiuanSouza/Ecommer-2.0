# Front-End

> Interface do usuário desenvolvida em React para consumir a API REST do E-commerce 2.0. Focada em ser responsiva, rápida e prover uma ótima experiência de navegação e compra.

## 🎨 Layout e Telas
- **Vitrine de Produtos**: Exibe todos os produtos disponíveis, integrando uma barra de busca para filtragem em tempo real.
- **Carrinho de Compras**: Gestão dinâmica dos itens (adicionar, remover, alterar quantidade) com os valores atualizados instantaneamente.
- **Autenticação**: Telas e fluxos para login e cadastro de usuários, protegidas por rotas privadas.
- **Histórico/Perfil**: Área onde o usuário autenticado pode conferir seus pedidos anteriores.

## 🛠 Tecnologias e Bibliotecas
- React 19
- Vite
- React Router Dom (para o roteamento)
- Axios (para requisições e consumo da API)
- React Icons

## 🚀 Como Rodar o Front-End
1. Certifique-se de que o Back-End está rodando localmente (ou use a URL de produção, se aplicável).
2. Instale as dependências:
   ```bash
   npm install
   ```
3. Inicie o servidor de desenvolvimento:
   ```bash
   npm run dev
   ```
